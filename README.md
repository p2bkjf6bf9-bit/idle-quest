# はるかなる遠征 — 放置RPG

ブラウザだけで遊べるテキスト放置RPG。インストール不要、サインイン不要。

**▶ 遊ぶ: https://p2bkjf6bf9-bit.github.io/idle-quest/**

## 遊びかた

1. 装備（武器・盾・防具・アイテム）を整える。装備が欠けていても出発できる
2. ステージを選んで出発する
3. あとは放っておく。戦闘はリアルタイムのログで進む
4. 指定時間で帰還。経験値と戦利品を持ち帰る

同じ系統の装備を2つ揃えると能力が1.25倍、3つ揃うと1.5倍になる。

| ステージ | 所要時間 | 目安 |
|---|---|---|
| 🌿 はじまりの草原 | 5分 | 装備なしでも帰れる |
| 🌲 ささやきの森 | 10分 | 装備を整えてから |
| 🏔️ 凍てつく峡谷 | 15分 | 生半可な装備では帰れない |

## セーブ

進行度はブラウザに自動保存される。端末を移るときは「セーブ書き出し」でデータをコピーし、移行先の「読み込み」に貼り付ける。セーブデータが外部に送られることはない。

## 構成

`index.html` 1ファイルのみ。外部ライブラリや通信は使っていない。
バランス調整用の数値はファイル冒頭の `BAL` とモンスター表にまとまっている。
